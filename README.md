# 📝 FinNotes

Лёгкий и быстрый менеджер заметок поверх игр и любых программ для Windows. Написан на **AutoHotkey v1.1** с использованием **HTML/CSS**.

## ✨ Особенности
* **Мгновенный вызов (`Alt + V`):** открывает окно быстрого ввода поверх любого приложения или игры без сворачивания.
* **Полноценный редактор:** поддержка абзацев (`Enter`), переносов строк и автоматическое определение активного окна/игры (контекста).
* **Карточная доска (`Alt + B`):** все заметки сохраняются в виде удобных карточек с датой создания, возможностью переименовать заголовок прямо в карточке, скопировать текст в один клик или удалить лишнее.
* **Чистый рабочий стол:** база заметок автоматически сохраняется в отдельную папку `Документы\Fines Notes`.

## 🎮 Горячие клавиши
* **`Alt + V`** — открыть окно создания новой заметки.
* **`Alt + B`** — открыть или развернуть главное окно со всеми заметками.
* **`Ctrl + Enter`** (в окне ввода) — сохранить заметку и открыть доску.
* **`Esc`** (в окне ввода) — закрыть окно без сохранения.

## 🚀 Как запустить
1. Скачай готовый файл `FinNotes.exe` из раздела **Releases** справа и запусти его.
2. Или запусти исходный код `FinNotes.ahk` с помощью установленного [AutoHotkey v1.1](https://autohotkey.com).
3. Чтобы закрыть программу вам нужно сделать это через Tray или Диспечер Задач.
